# Demos

The demo ladder is 12 scenes ordered simplest first. To open them, double-click
`addons/local_agents/examples/DemoLauncher.tscn` in the FileSystem dock, then click Run Current
Scene in the top-right toolbar. The launcher builds its rows from the catalogue this page comes
from: one `LocalAgentDemoEntry` resource per demo in `addons/local_agents/examples/demos/`. Drop a
`.tres` in that directory and a row appears in the launcher with no code to edit. The numbering
below is the launcher's own, taken from each entry's `order`.

A row whose Requires line names a GGUF model still opens when the file is on disk but has not been
loaded yet, since the demo loads it itself. The launcher greys that row out when the install is
missing something harder:

- the native extension did not load
- the AgentManager autoload is missing
- no `.gguf` file was found at all

A row that needs the godot_voxel GDExtension is greyed out when `addons/zylann.voxel/` is not
installed. Every other row opens no matter what is installed. `INSTALL.md` covers where a model comes
from and where to put it.

This page is generated by `scripts/gen_demos_doc.sh`. Run that script after you add or edit a
`.tres`, or `scripts/check_demo_catalog.sh` fails the build until the page matches the catalogue
again. Editing the page by hand does not last, because the next run of the generator overwrites your
text. Change the `.tres` for content, or the generator for wording.

## Running a demo headless

`scripts/run_demo.sh <name>` runs an example scene with no window in about a second and prints a
`RUN_DEMO={...}` line carrying the exit code. It only accepts a scene that builds a
`LocalAgentDemoHarness`, and 5 of the 12 entries have one. An example scene without that harness
ignores `--run-frames` and never exits, so it gets `--quit-after` instead. Each demo below carries
the command that applies to it.

`scripts/run_demo.sh --all` runs every harnessed demo in turn at 40 frames each, then prints a
`RUN_DEMO_ALL={"ran":N,"failed":N,"frames":N}` line and exits non-zero if any of them failed. Pass a
frame count to override the default, as in `scripts/run_demo.sh --all 200`.

`scripts/run_demo.sh --list` prints which is which. It walks the scenes in
`addons/local_agents/examples/` rather than the catalogue, so it also lists `DemoLauncher.tscn`,
the catalogue viewer, and it leaves out whatever the catalogue points to outside that
directory: `addons/local_agents/game/VoxelWorld.tscn`.

`LocalAgentDemoHarness` is not the only implementation of `--run-frames`. Whatever the catalogue
points to outside that directory parses the flag in its own scripts and quits when it reaches the
frame count, which is why the command for it below hands `--run-frames` to a scene with no harness.

To see what the launcher makes of the catalogue on this machine, including which rows it greys out
and why, run:

    godot --headless --path . addons/local_agents/examples/DemoLauncher.tscn -- --catalog-report

It prints a `DEMO_CATALOG={...}` line and quits.

## 1. Quickstart

The smallest thing that works: one LocalAgent node, a prompt box, a reply. Start here.

- Scene: `res://addons/local_agents/examples/AgentQuickstart.tscn`
- Requires: a GGUF model installed
- Run headless: `godot --headless --path . addons/local_agents/examples/AgentQuickstart.tscn --quit-after 120`, since it builds no harness.

## 2. The agent drives actions

The reply becomes game actions instead of text: the agent recolours and pulses an orb through enqueue_action. Buttons fire the identical actions, so the loop is visible with no model installed.

- Scene: `res://addons/local_agents/examples/AgentActionsDemo.tscn`
- Requires: nothing, it opens with no model installed
- Run headless: `godot --headless --path . addons/local_agents/examples/AgentActionsDemo.tscn --quit-after 120`, since it builds no harness.

## 3. Two agents converse

Ada and Ben take turns, and every line lands in a shared memory graph. With no model the turn-taking runs on canned lines, so the graph wiring still demonstrates.

- Scene: `res://addons/local_agents/examples/AgentConversationDemo.tscn`
- Requires: nothing, it opens with no model installed
- Run headless: `godot --headless --path . addons/local_agents/examples/AgentConversationDemo.tscn --quit-after 120`, since it builds no harness.

## 4. Chat

## 7. Guided tutorial overlay

The reusable tutorial system: a sequencer walks a spotlight from button to button with a callout on each. Nothing here is specific to agents, so any scene can reuse it for onboarding.

- Scene: `res://addons/local_agents/examples/TutorialDemo.tscn`
- Requires: nothing, it opens with no model installed
- Run headless: `scripts/run_demo.sh TutorialDemo`, or `scripts/run_demo.sh TutorialDemo 200` for more than the default 40 frames.

## 8. One creature, nothing else

The smallest creature scene there is: a single species from creatures/species/ standing on a flat floor. It references no field and no planet, which is what proves the creature stack runs on its own.

- Scene: `res://addons/local_agents/examples/CoreCreatureSmoke.tscn`
- Requires: nothing, it opens with no model installed
- Run headless: `scripts/run_demo.sh CoreCreatureSmoke`, or `scripts/run_demo.sh CoreCreatureSmoke 200` for more than the default 40 frames.

## 9. Thinking creatures on flat ground

## 10. Box-field heat sandbox

The simulation substrate in a bare box: inject heat at the floor, watch it diffuse and buoy upward through a tinted slice. One field, no planet wrapped around it.

- Requires: nothing, it opens with no model installed

## 11. A whole planet from one node

LocalAgentSimWorld in SPHERE mode: the cubed-sphere body, the material field and a living ecology from a single node, framed by a camera. There is no game shell around it, so no HUD, menus, disasters or streamer.

- Scene: `res://addons/local_agents/examples/SimWorldPlanetDemo.tscn`
- Requires: the godot_voxel GDExtension (addons/zylann.voxel/)
- Run headless: `scripts/run_demo.sh SimWorldPlanetDemo`, or `scripts/run_demo.sh SimWorldPlanetDemo 200` for more than the default 40 frames.

## 12. Play the planet

The whole game shell around the planet: herds, emergent disasters, a HUD and a local-LLM streamer commentating over the top. It needs a real window, because the GPU field has no compute device headless.

- Scene: `res://addons/local_agents/game/VoxelWorld.tscn`
- Requires: the godot_voxel GDExtension (addons/zylann.voxel/)
- Run: `scripts/run_sim_offscreen.sh --path . addons/local_agents/game/VoxelWorld.tscn -- --run-frames=200`. It lives outside `addons/local_agents/examples/`, so `scripts/run_demo.sh` cannot address it, and headless has no compute device for its field, so the wrapper gives it a real window placed off-screen.
